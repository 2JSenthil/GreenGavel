# Green Gavel frontend

Next.js app for Green Gavel OS. Setup, API, and data live in the repository [README](../README.md).

```bash
npm install
npm run dev
```

Open http://localhost:3000. `/api/*` is rewritten to the Python API (`API_PROXY`, default `http://127.0.0.1:8000`) unless the app is running on Vercel.
